# Roadmap
- [x] Winamp 2.0-style player: main, playlist, visuals windows, dragging/snapping, skins, llama intro
- [x] Support all browser-playable audio formats with clean full-quality playback
- [x] Save/restore playlists between visits (auto-restore queue + named playlists)
- [x] Package as a Windows 11 desktop app
- [x] Installable Windows setup .exe
- [x] Silver/gray frame skin with brighter button underlay, green matrix text kept
- [x] 10-band equalizer (Winamp bands, preamp, presets, ON toggle, persisted)
- [x] HiFi focus: lossless formats, clean EQ chain, playback latency hint
- [x] Auto-organized offline music library: folders, artists, albums, genres and search
- [x] Independent source browser windows with queue actions
- [x] Top-right compact / full-size player controls
- [x] Verify library import, persistence, source windows and size switching
- [x] Add plug-in settings with platform-aware support, live controls and saved settings
- [x] Verify plug-in toggles, configuration and playback
- [x] Resizable individual windows and joined diagonal resizing with separation and saved layouts
- [x] Advanced EQ controls and future enhancement plug-in availability
- [x] Verify three-window resizing, separation, saved layout and live EQ
