AMPLY · HIFI PLAYER ✕

A reverse-engineered tribute to the classic Winamp 2 — because it really whipped the Llama's ass.

Download for Windows Download for Linux Debian View on GitHub

Free · Public source code · Works offline · Windows & Debian Linux

FEATURES
  • Bit-perfect path — visuals only listen, never touch the sound.
  • 10-band EQ with presets, live dB readouts and Advanced EQ.
  • Music library auto-sorted by artist, album, genre and folder.
  • Playlists saved between sessions, fully offline.
  • Real desktop windows that snap to the player and move together.
  • Six skins — Silver, Classic, Nucleo, Ruby, Matrix, Modern.
GETTING STARTED · WINDOWS
  1. Download. Click Download for Windows at the top. The setup file saves to your Downloads folder.
  2. Open the file. Double-click the downloaded file. If a blue window says "Windows protected your PC", click More info, then Run anyway. This appears because AmPly is a free hobby app without a paid Microsoft certificate.
  3. Install. Click Next / Install and wait a few seconds. AmPly appears in your Start menu and on your desktop.
  4. Start AmPly. Open it and press Power on (or Skip) on the start screen.
  5. Add music. Drag songs into the Playlist window, or open the Library window and choose your music folder — it sorts by artist and album automatically. Your files are never moved.
  6. Make it yours. Drag windows close to the player and they snap together. Right-click a window's title to change the skin.
GETTING STARTED · DEBIAN LINUX
  1. Check your computer. This Linux test version is for Debian-based desktops with a 64-bit Intel or AMD processor. It is not for ARM computers or Raspberry Pi.
  2. Download or copy from USB. Click Download for Linux Debian above. Save amply_3.0.0_amd64.deb in Downloads. If you brought it on a USB stick, copy it into Downloads first.
  3. Install. Double-click the .deb file and choose Install if a software installer opens. Enter your account password when asked. Internet may be needed for missing system packages.
  4. No installer opens? In your file manager, open Downloads, right-click an empty space and choose Open in Terminal. Paste sudo apt install ./amply_3.0.0_amd64.deb and press Enter. Type your password (nothing appears as you type) and confirm if asked.
  5. Start AmPly. Find AmPly HiFi Player in your applications menu, or type amply in a terminal. Press Power on or Skip. Do not start the player with sudo.
  6. Add your music. Drag songs into Playlist or choose your music folder in Library. Your original files stay where they are; imported music and playlists work offline after setup.
  7. Need help? If it will not open, run amply in a terminal and send the error text and your Debian version through Contact me. More help is in the Linux setup guide on GitHub.
